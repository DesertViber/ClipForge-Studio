# Testing ClipForge Studio

Thanks for helping test this local Windows application.

## Before reporting a bug
- Use Python 3.11 or 3.12 and install FFmpeg/FFprobe in PATH.
- Start the app using `start_windows.bat` and open http://127.0.0.1:8765.
- Reproduce the problem with sample media you have permission to use.
- Do **not** upload your `data/` directory, audio files, transcripts, database, API keys or private paths.

## Useful bug report
- Windows version, Python version and browser
- Expected behavior versus actual behavior
- Reproduction steps
- Console traceback or browser console error with private details redacted

## Current focus
- Home navigation from all secondary workspaces
- Immediate soundboard pad color preview and persistence after saving
- Episode editor, clip import, waveform display and teleprompter behavior

This repository is a testing snapshot, not a security-hardened public server.
